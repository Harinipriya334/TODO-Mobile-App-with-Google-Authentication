# Todo Task Management Mobile App

A cross-platform Todo Task Management Mobile App designed to help users efficiently organize and manage their daily tasks through a clean and intuitive interface.

## Features

* Social login using one provider
* Create, read, update, complete, and delete tasks
* Task fields:

  * Title
  * Description
  * Due date
  * Status
  * Priority
* Local state storage for session-based task management
* Task tabs and filtering options
* Search functionality
* Floating Action Button for quick task creation
* No-data state for empty task lists
* Pull-to-refresh functionality
* Swipe-to-delete tasks
* Smooth UI animations
* Crash reporting integration
* Scalable and maintainable application design

## Project Objective

The objective of this project is to develop a simple and user-friendly mobile application that allows users to manage their tasks efficiently. The application provides authentication, task management, search, filtering, and other productivity features in a single platform.

## Technology Stack

* Flutter / React Native
* Dart / TypeScript
* Social Authentication
* Local State Storage
* Git & GitHub

## Application Workflow

1. User opens the application.
2. User signs in using the available social login provider.
3. User accesses the task management dashboard.
4. User can create new tasks with title, description, due date, status, and priority.
5. User can edit, complete, search, filter, or delete tasks.
6. Tasks are maintained using local session storage.
7. The application provides refresh, swipe-to-delete, and smooth animation features.

## Project Structure

The project is organized to maintain a clean and scalable application structure, making the code easier to manage, maintain, and extend.
